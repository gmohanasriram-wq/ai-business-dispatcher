# Demo Scenarios

*Planned demonstration scenarios for the AI Business Dispatcher.*

## Target Business: Home Service (Plumbing)

The first demo target is a home-service business such as a plumbing company.

### Scenario 1: Emergency Service Request
- Customer calls with a burst pipe emergency.
- Voice agent collects address, contact, and urgency.
- n8n workflow prioritizes and dispatches to nearest available plumber.
- Backend logs the request and schedules follow-up.

### Scenario 2: Appointment Scheduling
- Customer calls to schedule a routine inspection.
- Voice agent checks calendar availability via integrated system.
- Appointment is booked and confirmation sent via SMS/email.
- Backend updates customer database and triggers reminder workflow.

### Scenario 3: Invoice and Payment Follow-up
- After service completion, voice agent calls to collect payment.
- Integrates with payment gateway and updates accounting system.
- Failed attempts trigger retry workflow and notifications.

## Notes

These scenarios are planned for future implementation. Current phase focuses on project foundation only.
